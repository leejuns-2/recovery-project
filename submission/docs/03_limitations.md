# Limitations

| Limitation | Consequence |
|---|---|
| LOEO R²가 0.1148로 낮음 | 새 호우 이벤트의 절대 회복률을 정밀하게 예측한다고 보기 어려움 |
| delayed가 관측된 이벤트가 16개 | 이벤트별 랭킹 지표의 안정성 판단에 사용할 표본이 제한적 |
| 생활인구 회복률을 타깃으로 사용 | 복구 완료나 주민 피해를 직접 측정하지 않음 |
| 직접 행정수요 실적이 없음 | 민원·폐기물·현장점검 수요와의 관계를 검증하지 못함 |
| 침수흔적 overlap이 낮음 | 물리적 침수 발생 예측의 근거로 사용할 수 없음 |
| `duration_days`의 가용 시점 | 이벤트 종료 뒤 D+1~D+3 갱신에서만 사용 가능 |
| What-if와 capacity scenario | 정책의 인과효과가 아니라 동일 가정 아래의 상대 효율 민감도 |
| 서울 데이터에 한정 | 다른 지역에 적용하려면 데이터 정의와 모델 재보정이 필요 |

## Interpretation Boundaries

결과는 생활활동 회복지연 가능성이 큰 행정동을 먼저 확인하기 위한 순위입니다. 침수 발생, 정확한 회복 완료일, 민원·폐기물·현장점검 건수를 직접 예측하지 않습니다.

Recall과 Lift@Top-K가 높더라도 낮은 LOEO R²가 사라지는 것은 아닙니다. 랭킹 지표는 제한자원 배치 문제에 대한 평가이고, R²는 절대 회복률 일반화에 대한 평가입니다. 두 결과를 함께 봐야 합니다.

외부 행정수요 자료가 확보되면 위험 상·하위 그룹의 관측 실적을 비교해야 합니다. 그 전에는 위험 상위 동에서 실제 행정수요가 높다고 단정할 수 없습니다.
