# Competition Positioning

## 공모전 적합성

2026 기후부 AX 아이디어 경진대회는 기후·환경·에너지 분야 공공·민간 데이터와 AI를 활용하여 정책현안 해결, 데이터 기반 혁신, 서비스 또는 분석 결과를 제안하는 대회입니다. 공개 안내에 따르면 활용 분야는 아이디어/제품·서비스, 분석 분야는 자유/지정 분석으로 나뉘며, 정책 의사결정에 활용 가능한 분석과 시각화가 주요 제출 형태입니다.

이 프로젝트는 `물환경/수자원`, `생활환경`, `기후변화 대응`, `환경통계` 영역에 걸친 자유 분석 과제로 포지셔닝하는 것이 적합합니다.

## 다른 수상형 주제 대비 이점

| 비교 축 | 일반적인 강한 수상작 | 본 프로젝트의 이점 |
|---|---|---|
| 문제 명확성 | 생활 속 환경 문제 또는 정책현안이 분명함 | 집중호우 이후 복구자원 우선배치라는 행정 의사결정 문제가 선명함 |
| 데이터 융합 | 공공데이터 여러 개를 결합 | 생활인구, 강수, 침수흔적, 하수도, 복지·행정시설 결합 |
| AI 활용 | 예측/분류/최적화/시각화 | XGBoost, LOEO, SHAP, Top-K 랭킹, capacity scenario |
| 정책 활용성 | 결과가 실제 업무표로 이어짐 | event priority table, playbook, capacity scenario가 바로 행정 문서 형태 |
| 설명 가능성 | 모델 결과를 사람이 이해 가능 | top_reason_1~3, recovery_type, recommended_action 제공 |
| 확장성 | 다른 지역/기관 데이터로 확장 가능 | 서울 행정동 단위에서 시작해 타 지자체 회복운영 모듈로 확장 가능 |

## 약점

| 약점 | 영향 | 방어 방식 |
|---|---|---|
| LOEO R2가 낮음 | 정밀 예측 모델로 보이면 감점 | 운영형 랭킹 모델로 포지셔닝 |
| delayed 발생 이벤트가 16개 | 이벤트별 안정성 주장 제한 | event-wise lift는 delayed 발생 이벤트 기준으로 명시 |
| 생활인구는 복구 완료가 아님 | 타깃 타당성 공격 가능 | 생활활동 정상화 대리지표로 제한 |
| 침수흔적 overlap이 낮음 | 물리적 침수 검증으로 쓰기 어려움 | 침수면적보다 사후 운영 취약성 포착으로 해석 |
| 제품화 수준은 아직 낮음 | 활용/제품서비스 부문에서는 약점 | 분석 부문으로 제출하고 Streamlit 데모는 보조 시연으로 사용 |

## 수상 가능성 판단

분석 부문 기준으로는 **우수상권 도전 가능성 있음**으로 판단합니다. 이유는 단순 예측 모델이 아니라 우선순위표와 플레이북까지 이어지는 정책 의사결정 산출물이 있기 때문입니다.

대상권으로 가려면 다음 중 최소 하나가 더 필요합니다.

- 실제 행정 담당자가 보는 대시보드 또는 AI Agent 데모
- 민원/폐기물/현장점검 등 외부 실적 데이터와의 추가 검증
- 특정 호우 사례에 대한 발표용 스토리라인 강화
- 제출 문서에서 “R2 낮음”을 약점이 아니라 “랭킹 목적 지표 전환”으로 명확히 설계

## 추천 제출 전략

분석 부문 자유 분석으로 제출하고, 발표에서는 다음 문장을 반복합니다.

> 본 모델은 침수 발생을 예측하거나 회복 완료일을 정밀 예측하는 모델이 아니라, 집중호우 이후 제한된 복구자원을 우선 투입해야 할 생활활동 회복지연 위험 행정동을 선별하는 운영형 랭킹 모델이다.

## 기존 취약성 분석 대비 차별점

| 기존 접근 | 본 과제의 차별점 |
|---|---|
| 침수위험·침수흔적 지도 | 물리적으로 잠길 수 있는 곳이 아니라, 비가 그친 뒤 생활활동 회복이 늦을 곳을 선별 |
| 장기 기후취약성 예측 | 2050/2100년 전망이 아니라 호우 종료 직후 D+1 운영 판단 지원 |
| 예측 정확도 중심 모델 | 제한자원 우선배치를 위한 Top-K Recall, Lift, Precision 중심 평가 |
| 취약지역 설명형 분석 | `event_priority_table`, `playbook_table`, Streamlit 대시보드로 담당부서와 조치시점까지 연결 |
