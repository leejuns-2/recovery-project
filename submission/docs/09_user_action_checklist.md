# User Action Checklist

## 제출 전 판단

현재 제출본은 추가 행정수요 자료 없이도 진행 가능하다. 다만 민원·폐기물·현장점검 중 1개 자료를 확보하면 관측 행정수요와의 직접 검증을 추가할 수 있어 방어력이 커진다.

## 반드시 직접 해야 할 일

| 우선순위 | 할 일 | 왜 필요한가 | 최소 확보 단위 | 제출 반영 위치 |
|---:|---|---|---|---|
| 1 | 문서 표현 점검 | 관측 행정수요 직접 예측으로 오해되지 않게 방어 | “잠재 행정수요 우선점검 후보” 표현 유지 | README, 분석보고서, 발표자료 |
| 2 | 대시보드와 우선순위표 캡처 | 심사위원에게 실제 산출물 완성도를 보여줌 | Streamlit 첫 화면, Top20 표, 지도/성능 그래프 | 발표자료 또는 보고서 그림 |
| 3 | 제출 전 산출물 파일 존재 여부 확인 | 보고서 서술과 제출 패키지 불일치 방지 | `submission/assets` 전체 | `submission/manifest.csv` |
| 4 | 발표용 한 문장 고정 | 주제가 한 번에 기억되게 함 | “침수위험과 회복지연위험은 다르다” | 제목, 첫 장, 결론 |

## 선택 보강하면 좋은 일

| 우선순위 | 할 일 | 왜 필요한가 | 최소 확보 단위 | 제출 반영 위치 |
|---:|---|---|---|---|
| 1 | 민원·폐기물·현장점검 중 1개 외부 실적 데이터 확보 | 잠재 행정수요 후보가 관측 행정수요와 같은 방향인지 직접 검증 | `event_id x adm_cd`, 어려우면 `event_id x gu_nm` | `data/external/external_validation_template.csv` |

## 외부 실적 데이터 요청 문안

아래 문안을 서울시 또는 자치구 재난안전과, 치수과, 청소행정과, 민원 담당부서에 맞춰 보낼 수 있다.

```text
안녕하세요.

집중호우 이후 행정동별 생활서비스 회복 지연과 복구자원 우선배치 분석을 수행 중입니다.
모델 결과가 실제 사후 행정수요와 연결되는지 검증하기 위해 아래 기간·단위의 집계자료 제공 가능 여부를 문의드립니다.

요청 기간:
- 2023-07-13 ~ 2023-07-20
- 2024-07-18 ~ 2024-07-25
- 2025-09-04 ~ 2025-09-11

요청 단위:
- 가능하면 행정동별 일별 또는 기간합계
- 어려우면 자치구별 기간합계

요청 지표 중 가능한 항목:
- 침수, 배수, 도로불편, 생활불편 민원 건수
- 빗물받이, 배수로, 도로 등 현장점검 건수
- 수해 폐기물 또는 침수잔재 수거량
- 피해신고 접수 건수

개인정보나 민원 원문은 필요하지 않으며, 행정동/자치구별 집계값만 사용합니다.
자료는 연구·공모전 검증 목적의 통계 분석에만 활용하겠습니다.
```

자료를 받지 못한 경우에도 제출 문구는 다음처럼 유지한다.

```text
본 제출본은 관측 행정수요를 직접 예측하지 않고, 생활인구 회복지연을 기준으로 잠재 행정수요 우선점검 후보를 선별합니다. 민원·점검·폐기물 자료는 향후 직접 검증 보강 항목으로 남깁니다.
```

## 데이터를 받았을 때 넣는 형식

`data/external/external_validation_template.csv`에 아래 컬럼을 채운다.

```text
event_id,event_date,adm_cd,adm_nm,gu_nm,complaint_count_d0_d7,waste_ton_d0_d7,field_check_count_d0_d7,damage_report_count_d0_d7,source_note
```

행정동 코드가 없으면 `adm_nm`, `gu_nm`만 먼저 채우고, 행정동 코드 매핑은 별도로 보완한다. 자치구 단위만 받은 경우에는 `adm_cd`를 비워두고 보조 검증으로 낮춰 표현한다.

## 자료 확보 후 실행

```powershell
python scripts\external_validation.py
```

외부 실적 값이 들어 있으면 `outputs/external_validation_summary.csv`와 `submission/assets/external_validation_summary.csv`가 Top20/Bottom20 비교표로 갱신된다.
