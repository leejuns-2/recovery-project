# Limitations and Defense

## Limitations

| Limitation | Defense |
|---|---|
| LOEO R2가 낮음 | 절대값 예측이 아니라 Top-K 우선순위 선별 목적 |
| delayed 발생 이벤트가 16개 | event-wise 지표는 delayed 발생 이벤트 기준으로 해석 |
| 생활인구 회복률은 복구 완료가 아님 | 생활활동 정상화의 조기 신호로 제한 |
| 직접 행정수요 실적 데이터 부재 | 관측 행정수요 예측이 아니라 잠재 행정수요 우선점검 후보 선별로 범위 제한 |
| 침수흔적 overlap이 낮음 | 모델은 과거 침수면적보다 사후 운영 취약성을 포착 |
| `duration_days` 사용 가능 시점 | D+1~D+3 운영 갱신 모델에서만 사용 |
| What-if/capacity scenario | 인과효과가 아니라 동일 가정하 상대 효율 민감도 |
| 서울시 한정 | 타 지역 적용 시 재보정 필요 |

## Safe Claims

- 위험 상위 20% 동은 전체 평균 대비 delayed 위험이 높게 농축됩니다.
- 상위 20% 선별만으로 전체 delayed 동의 82.2%를 포착했습니다.
- 제한자원 조건에서 위험기반 선별은 무작위 배치보다 delayed 포착 효율이 높습니다.
- 결과물은 모델 점수에서 끝나지 않고 우선순위표와 조치 플레이북으로 연결됩니다.
- 현재 산출물은 관측 행정수요 직접 예측이 아니라 잠재 행정수요 우선점검 후보 선별입니다.
- 민원·점검·폐기물 자료가 확보되면 동일 템플릿으로 직접 행정수요 검증을 추가할 수 있습니다.

## Unsafe Claims

- 회복 완료일을 정확히 예측한다.
- 침수 발생 자체를 사전 예측한다.
- 하수도/복지시설 투자의 인과효과를 추정했다.
- What-if 결과가 실제 정책효과다.
- 생활인구 회복률이 복구 완료를 의미한다.
- 위험 상위 동은 실제 민원·점검·폐기물 수요가 높다고 이미 검증되었다.
